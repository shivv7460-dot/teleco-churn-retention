# Telco Customer Churn Prediction & Retention Optimizer

## Setup
1. Place `WA_Fn-UseC_-Telco-Customer-Churn.csv` inside `data/`.
2. Install dependencies: `pip install -r requirements.txt`
3. Load & clean data into SQLite: `python src/load_to_sql.py`
4. Run exploratory SQL queries: `python src/run_sql.py`
